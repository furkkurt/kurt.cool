1. Engine Architecture, Human-Machine Interfaces (HMI) & Simulation

Temple Engine — Browser-Based 3D Game Engine & Visual Editor
Capstone Thesis • 2026
TypeScript Three.js / WebGL React Zustand cannon-es ECS Architecture EventBus Vite

A full-featured 3D game engine core and visual editor running entirely in the browser, built from scratch with modern web standards and inspired by Unity's productive workflow. Rather than a superficial demo, it is an exercise in decoupled engine architecture where rendering is strictly isolated behind an adapter layer.

Architecture: [React + Zustand Editor UI] ──API/Events──► [Pure TS Engine Core (ECS + EventBus + Loop)] ──Adapter──► [Three.js / WebGL]
  • Renderer-Agnostic Engine Core: Implemented Scene, Entity, Component, and System hierarchies in pure TypeScript with zero runtime dependency on Three.js. Three.js is positioned strictly as a swappable renderer adapter responsible only for Object3D synchronization, camera mapping, and WebGL draws.
  • Deterministic Fixed-Timestep Loop: Decoupled variable frame rendering from simulation physics using an accumulator-based delta/fixed-timestep loop, preventing tunneling and jitter in cannon-es rigid-body collision simulations.
  • Visual IDE & State Management: Built an interactive editor with React and Zustand featuring a live scene hierarchy tree, 3D viewport with transformation gizmos (Translate/Rotate/Scale), dynamic component inspector, GLB asset loading, and Play/Stop modes with automated scene snapshot memory restoration.
  • Engineering Outcome: Delivers desktop-grade developer ergonomics in a web environment; serializes scenes into clean, human-readable JSON capable of packaging into desktop binaries (via Electron/Tauri) or Android APKs.
Real-Time Hand Gesture Recognition & HMI Input System — Computer Vision-Based OS Controller
Computer Vision & HMI • 2026
Python OpenCV MediaPipe (3D Landmarks) Linux X11 (xdotool) Tkinter Overlay HUD HMI Architecture

A low-latency, modular Human-Machine Interface (HMI) pipeline that tracks 3D hand joints from a standard webcam feed in real time and translates biometric gestures into native operating system keyboard and mouse events. Fully documented with an accompanying academic research paper.

  • 3D Joint Tracking & Palm Orientation Algorithm: Analyzes MediaPipe 3D landmark coordinates to calculate palm normal vectors in real time, automatically toggling between Typing Mode (palm facing forward) and Mouse Navigation Mode (palm facing backward).
  • Chorded T9 Finger Typing State Machine: Designed a temporal state machine detecting thumb-to-finger tap counts (1-4 taps) with calibrated timing windows (`COMMIT_IDLE_MS`, `TAP_WINDOW_MS`), enabling full alphanumeric text entry and two-hand number counting.
  • OS-Level Execution & Telemetry HUD: Emits native Linux X11 inputs via `xdotool` directly to focused desktop applications with sub-frame latency. A transparent Tkinter on-screen display (Overlay HUD) renders live pinch thresholds and telemetry without stealing window focus.
  • Industry Relevance: Offers hands-free, touchless control suitable for sterile medical consoles, aerospace ground stations, and industrial operator environments.

Ashe's Touch (eyeOfTheBeholder) — 1.44 MB Size-Constrained Retro Adventure Game
Systems & Game Programming (Rust) • 2026
Rust 2021 Macroquad Custom quad-snd Patch LTO (Link-Time Optimization) UPX Compression Linux X11/PipeWire/ALSA Windows Cross-Compile

A systems programming project built for the 1.44 MB Game Jam, where the entire standalone executable—including graphics, sound generation, level geometry, and game engine—strictly remains under 1,474,560 bytes (the size of a 3.5" floppy disk).

  • Aggressive Binary Footprint Optimization: Configured release profiles with `opt-level = "z"`, fat Link-Time Optimization (`lto = "fat"`), single codegen units, panic abortion, and symbol stripping, compressed via UPX to compress the entire engine and assets under the megabyte barrier.
  • Procedural In-Memory Audio Synthesis: Rather than embedding heavy audio waveforms, patched the `quad-snd` crate to generate algorithmic 8-bit sound effects procedurally at runtime using mathematical sine/square synthesis with 0 KB file footprint.
  • Dual-Target Cross-Compilation: Developed natively on Void Linux (X11, ALSA, PipeWire) with automated MinGW cross-compilation scripts (`CROSS_WINDOWS=1`) delivering verified dual-platform release binaries.
