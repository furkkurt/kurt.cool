## Project Overview

A fully customizable navigation component system inspired by early 2000s web design patterns. Built with modern web technologies but styled with retro Y2K aesthetics.

### Features

- Animated neon borders
- Glitch effects on hover
- Grid-based layouts
- Fully responsive design

### Technologies

- HTML5
- CSS3 Animations
- Vanilla JavaScript
